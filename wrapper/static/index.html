Connect your TikTok account

The bridge signs you in through TikTok's own login page (a QR code shown right here, or a real browser window on this machine for password login), then reads your conversations on the backend.

Don't know your password or email? Scan a QR code — open TikTok on your phone, go to Profile → menu → Scan, and approve. It is passwordless and the safest option.

How your data is handled

Before you log in, here is exactly what happens to your credentials, session and messages. This is enforced in code, not just described.

Your password is never storedYou type it into TikTok's own page. The bridge never receives or persists it — only the resulting session.
Session sealed at restThe session is additionally stored as an AES-GCM blob (a per-login data key, wrapped by a master key). The browser profile and the local message cache on this machine are not encrypted; both are deleted on logout.
Deleted on logoutLog out and every trace — session, messages, contacts and the browser profile — is wiped from this machine.
One stable identity, log in onceYour browser profile is created once and reused, so after the first login the saved session is reused with no new login — never a fresh fingerprint each time (which is also what avoids rate limits).

This is a tester for a case study, run locally. Use a throwaway account.
